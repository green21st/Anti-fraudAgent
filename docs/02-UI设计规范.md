# 智盾反诈 UI 设计规范（双主题）

> 参考：modao.cc「AI agent 智能体对话」系列界面风格 —— 紫色主色调、白色圆角卡片、浅灰紫背景、柔和投影、胶囊筛选、环形评分与进度条组件。
> 所有颜色以 CSS 变量形式定义在 `App.vue` 的 `.page` / `.page--dark` 中，组件内只引用变量。

## 二、主题机制

- 状态：`uni.getStorageSync('app_theme')`（`light` / `dark`），默认浅色；
- 根节点绑定：`:class="{ 'page--dark': isDark }"`；
- 全局混入（`main.js` themeMixin）为每个页面提供 `isDark` 与 `toggleTheme()`；
- 切换入口：每页右上角 🌙/☀️ 圆钮 + 「我的」页外观设置分段选择器。

## 三、字体

- 大标题 40rpx/800、页面标题 32-36rpx/700、正文 26-28rpx/400、辅助 22-24rpx；
- 数字强调（评分/统计）48-72rpx/800。

## 四、组件规范

| 组件 | 规格 |
|---|---|
| 卡片 card | 圆角 28rpx，内边距 28rpx，投影 var(--shadow) |
| 模式卡 | 紫色渐变整卡，图标右侧 80rpx，用于首页双入口 |
| 胶囊 chips | 圆角 999rpx；选中=主色实底白字，未选=card-2 底 |
| 标签 tag | 20rpx 圆角 8rpx 软底色字（紫/橙/绿/红/蓝） |
| 按钮 | 主按钮渐变胶囊；次按钮 accent-soft 底；危险按钮红底 |
| 头像 avatar-circle | 84rpx 圆形 accent-soft 底 emoji；可疑联系人红色描边 |
| 进度条 | 16rpx 高胶囊轨道 + 紫渐变填充 |
| 环形评分 | conic-gradient 主色扇区 + 内圆 card 底，72 分显示 |
| 聊天气泡 | 圆角 20rpx、对角 6rpx；骗子白卡泡、用户绿泡；转账卡片红描边 |
| 底部 Tab Bar | 自定义组件，emoji 图标 + 文字，选中主色加粗 |
| 顶部导航 nav-bar | 自定义 sticky 导航：‹ 返回 + 居中标题 + 🌙 主题钮 |

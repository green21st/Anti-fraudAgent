# 反诈骗 Agent 需求与技术文档

> 项目：智盾反诈（反诈 Agent 智能训练与法律自救 App）
> 技术栈：uni-app（Vue 3）· HBuilderX
> 版本：v1.0.0（2026-10-20）

## 一、项目背景

电信网络诈骗高发，传统宣传式反诈教育转化率低。本项目通过 **与 AI 骗子真人对练** 的方式，让用户在安全的模拟环境中亲历诈骗话术，从而建立"肌肉记忆"式的防骗能力；同时为已受骗人群提供 **法律自救路径**。

## 二、核心 Agent 架构

| Agent | 职责 | 对应界面 |
|---|---|---|
| 欺诈训练 Agent | 扮演骗子进行一对一/多人情景演练 | chat-1v1 / multi-chat / multi-detail |
| 评估 Agent | 对训练表现做六维评分、失误回放 | report |
| 救助 Agent | 被骗后的追问式引导与六步方案 | rescue |

## 三、用户旅程

```
登录 → 个人画像 → 模式选择（欺诈训练 / 法律自救）
  ├─ 欺诈训练：场景库 → 一对一训练 / 多人找骗子 → 评估报告 → 错题本
  └─ 法律自救：热线 → 追问式对话 → 六步方案打卡
```

## 四、功能模块清单

1. **登录页 login**：微信一键登录 / 游客模式；三 Agent 能力介绍。
2. **个人画像 profile**：6 类字段（年龄段/职业/常用设备/上网习惯/受骗经历/关注场景）+ 合规提示 + 深浅色主题切换。
3. **首页 home**：欺诈训练 / 法律自救双入口、训练数据统计、快捷入口、今日推荐场景。
4. **场景库 scenarios**：8 大高发电诈场景（冒充公检法、刷单返利、杀猪盘、冒充客服退款、冒充熟人借钱、虚假投资理财、网络贷款诈骗、冒充军警采购），含难度/高发/训练形式标签与筛选。
5. **一对一训练 chat-1v1**：微信风气泡对话（骗子白泡、用户绿泡）、"模拟演练"转账卡片、三种应对抉择、识破点提示、自由输入应对、关键词信号检测。
6. **多人找骗子 multi-chat**：1 位骗子混入 4 位联系人的聊天列表。
7. **多人对话 multi-detail**：群聊逐条播放，实时捕获风险信号（虚假截图/保本承诺/诱导下载APP/制造稀缺/群托），一键标记骗子并给出正误反馈。
8. **评估报告 report**：综合评分（72 良好）环形图、六维评分（风险识别/信息保护/应变能力/心理素质/法律意识/反诈知识）、失误回放。
9. **错题本 mistake-book**：翻车现场 / 防范建议 / 关联法条 三段式卡片，支持按场景筛选。
10. **法律自救 rescue**：110 / 96110 / 12348 热线一键拨号、追问式进度（第 N/6 步）、六步方案打卡、关键词问答、免责声明。

## 五、合规要求

- 所有"骗子"均为 AI 模拟角色，训练内容仅用于反诈教育；
- 转账必须以"模拟演练"卡片形式呈现，不得出现真实支付；
- 自救模块必须包含免责声明，不构成正式法律意见；
- 不收集真实个人身份信息，画像数据仅本地保存。

## 六、UI 设计要求

- 参考成熟 SaaS 移动端设计（紫色主色调、白卡浅灰紫底、大圆角、柔和投影），详见《02-UI设计规范.md》；
- 支持浅色 / 深色紫双主题，任意页面右上角 🌙/☀️ 一键切换，偏好本地持久化；
- 一对一训练保留微信风格气泡（#95EC69 绿泡）以增强真实感。
